# Security Policy

## Supported versions

PyMPFIT is an early-stage research tool. Security-relevant fixes are applied to the
latest release on PyPI.

## Reporting a vulnerability

PyMPFIT is a scientific-computing package that fits partial charges from local
quantum-chemistry data, so its security surface is limited. If you do find a security
issue, please report it privately rather than opening a public issue:

- Preferred: GitHub's [private vulnerability reporting](https://github.com/shehan807/pympfit/security/advisories/new).
- Alternatively, contact the maintainer through the GitHub project page.

Please do not disclose the issue publicly until a fix has been released. We will
acknowledge your report and work with you on a fix and a disclosure timeline.
