# Getting help with PyMPFIT

Thanks for using PyMPFIT! Here is where to go for help.

- **Documentation** — https://pympfit.readthedocs.io/ (installation, user guide, theory, and API reference).
- **Bug reports** — Open a [GitHub issue](https://github.com/shehan807/pympfit/issues/new/choose) using the **Bug report** template. Please include your PyMPFIT version, how you installed it, and a minimal example that reproduces the problem.
- **Feature requests** — Open a [GitHub issue](https://github.com/shehan807/pympfit/issues/new/choose) using the **Feature request** template.
- **Questions** — Search the [existing issues](https://github.com/shehan807/pympfit/issues) first; if your question hasn't been asked, open a new issue.

PyMPFIT is maintained by a small team, so please be patient and respectful when asking
for help — see our [Code of Conduct](CODE_OF_CONDUCT.md).
